## 🔧 Technical Details

### HTML Structure
- Uses `<table>` layout for maximum compatibility
- Inline CSS styles (required for emails)
- Proper DOCTYPE and meta tags
- Mobile viewport settings

### Typography
- System font stack for best rendering
- Font sizes: 13px - 28px
- Line height: 1.6 - 1.8
- Font weights: 500 - 700

### Spacing
- Outer padding: 40px
- Inner padding: 25px - 50px
- Margins: 8px - 16px between elements
- Border radius: 8px - 16px
